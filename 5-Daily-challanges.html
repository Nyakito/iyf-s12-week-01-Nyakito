My Journey Into Web Development

Published on September 24, 2026 by Nyakito Noah

Why I Started Learning Web Development

Technology has always interested me because of the different ways it can be used to solve problems and create useful solutions.

Web development gives me an opportunity to turn ideas into websites and applications that people can actually interact with.

Starting With HTML

HTML is the foundation of every webpage. Learning HTML has helped me understand how content is structured and how different elements communicate meaning to the browser.

I am particularly interested in semantic HTML because it allows developers to describe the purpose of different parts of a webpage rather than simply arranging content visuallyit's mainly beneficial to browsers, I think but okay, we just do it.

What Comes Next?

After becoming comfortable with HTML, I plan to learn CSS and use it to control the presentation and layout of my websites, as required in the above exercises.

JavaScript will come later, where I will be able to add interaction and functionality to the websites I create.
